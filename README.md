## About

Full Stack Developer with a strong background in building **scalable**, **high-performance** applications across the entire stack — from robust APIs to polished interfaces and cloud infrastructure.

I work primarily with **C# / .NET** on the backend and **Angular / React** on the frontend, applying practices such as **DDD**, **Clean Architecture**, and **CQRS** to keep systems clear, testable, and ready for growth.

Beyond shipping features, I care about **maintainability**, **team collaboration**, and solutions that hold up in real production environments.
